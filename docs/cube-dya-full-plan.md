# Cube 双模 DYA 全功能接入

开发分支：`codex/xingzhi-cube-dongle`，基于用户已验证 USB DYA 连接的 `83738c3356a709d589c2256333bc775ca69ca44e`。临时全功能分支的改动已快进合回此分支，后续统一在此继续；不继续开发 USB-only 版。用户取消“默认解锁”改动，保持物理解锁与超时策略。

## 必须完成的能力

- USB 与 BLE Studio GATT 配置，独立会话与断线隔离、分帧、加密身份检查、有限队列、MTU 分片与确认重发控制。
- 动态 keymap 层：新增、删除、重排、重命名、默认层及按连接目标/OS 的默认层。
- 运行时宏与组合键：定义、编辑、执行、持久化和输入释放保障。
- 蓝牙五卡槽管理：命名、选择、解绑、输出优先级；不误删左右手绑定。
- 快速 keymap、设备信息、电量、输入流、扫描诊断、功耗与相关自定义设置，按实际能力注册 DYA 子系统。
- 轨迹球与编码器的软件配置、输入事件路径和 USB/BLE 鼠标、滚轮/传感器旋转行为；当前 Velvet 无这些物理模块，报告硬件数量为零，不伪造运动或硬件数据。
- 已保存 V1 keymap 数据迁移；保持小智、主题、语音/按键切换、原下载恢复方式和现有绑定。

## 验证与交付规则

用户于 2026-10-14 要求节省 GitHub Actions 额度：开发期间仅提交代码并运行本地主机测试，固件构建与远程测试改为手动触发。全部特性提交后才统一编译，不为每批提交重复运行 Action。

以 DYA 当前公开协议及 Cormoran 模块协议为依据，绑定具体源版本。支持的 RPC 必须产生真实状态变化和真实保存结果；未完成能力不注册，不用空数据成功响应冒充实现。主机测试用上游 protobuf 生成器独立交叉验证，状态机使用 ASAN/UBSAN。

每批变更在双模构建中验证，运行核心回归检查，不触发 USB-only 构建。最终仍需 Cube、左右手及实际轨迹球/编码器硬件完成相应实机验证。编译及模拟输入不能替代实机验证。

## 2026-10-15 接入批次（待统一 SDK 构建）

- Mod-tap / layer-tap：物理按键 hold-preferred 状态机，短按真实按下/释放，长按与打断判断，按下时锁存计时阈值，取消后不重放。DYA 可绑定两个参数；通用设置可调整 `hold_tap.term_ms`（1–5000ms，默认200ms）。不把合成组合键当成 hold-tap 物理按键。
- 鼠标：共用 USB/BLE HID ID3，五按钮、16位相对XY、垂直/水平滚轮；重复相同位移仍各发送一次，GET_REPORT 不重放位移；退出、断线、端点切换的释放屏障包含鼠标按钮。BOOT 键盘协议不宣称支持鼠标。
- 原生分体 GATT：订阅编码器、input-split、relay 三类通知，先检查加密身份与连接代次，独立重组每一半的原生 relay 分片。可选功能发现遇到忙会重试，不阻断键盘位置主通路。
- 左右手：实际活动设置读回确认、扫描诊断 `KDq/KDr` 和看门狗 `wdq/wdp` 原生转发。响应带来源和请求编号，按原 Studio 会话发送；超时、队列满、断线不伪造成功。左右手固件启用并固定对应模块源码；生产关闭危险故障注入。
- 指点配置 `cormoran_rip`：速度倍率、旋转、轴交换/反转、活动层、临时层、轴吸附、XY滚动、惯性与快速输入参数，保存/内存/临时模式及状态通知。最多四个分体 input-split 通道；没有硬件时数量为零，不伪造 PMW3610 芯片。
- 编码器 `cormoran_rsr`：从键盘的加密能力特征读取实际传感器数量和每圈触发数，正反转按层绑定、按下/释放队列，支持键/媒体/层/主机动作/宏。最多每半两个；当前键盘没有模块，正常返回零个。
- 其他页面：快速 keymap 全十项读取接口、只在解锁会话发送的输入流、六端点默认层与OS映射、BLE五卡槽OS手动覆盖、USB描述符观测分类、通用设置列表/读写/保存/撤销/重置/数组/分块/用户keyspace，以及实际外设的物理布局清单。
- USB OS 分类属于枚举指纹推断；Apple USB无法区分macOS/iOS，Linux/Android同理。BLE 未取得可靠观测时显示未知，可逐卡槽手动覆盖；不得从本机正在运行macOS推断连接目标。
- 固件为 ESP-IDF，不伪装成 Zephyr，也不注册不存在的 PMW3610 / Zephyr 专属配置界面。新的外围布局若没有坐标元数据，不捏造安装位置。

本批仍处于代码和本地测试阶段。最终只统一编译双模 Cube 与左右手；SDK 编译成功也不等于上述新增路径已实机验证。
