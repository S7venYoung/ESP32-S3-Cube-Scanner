# Cube 双模版的 DYA 配置

2026-10-14：用户确认当前双模固件硬件验证成功。后续下载包名称为 `Cube-Dual-Dongle`，不再带未验证后缀。此确认针对当前已实现功能，不代表下述仍未实现的高级功能已完成；`.bin` 文件名保留以兼容现有刷机工具。

仅 `xingzhi_cube_dual_candidate.bin` 启用。USB-only 版不新增此配置功能；本版本保留 USB 和电脑蓝牙键盘输出、小智和全部现有主题。

1. 退出 macOS 同步程序、串口监视器和刷机工具，避免占用 CDC。
2. Cube 正常开机连接 USB；在 Chrome/Edge 打开 https://studio.dya.cormoran.works/ ，选择 USB 和运行态 `Cube ZMK Dongle Candidate`。不要进入 ROM 下载模式。
3. 双击 Cube 的 BOOT，解锁写入五分钟。短按仍为小智对话；长按是下载模式，请勿混淆。
4. 可读取原始 61 键物理布局和默认 BASE/NVA/SYS 三层、修改绑定和层名、保存、撤销未保存修改。新增/删除/重排/恢复层已接入，当前最多四层。保存返回成功前会检查 NVS 提交结果，重启后恢复已保存配置。

当前支持：普通键、组合修饰键、透明/禁用键、瞬时层、音量加减/静音、BT_SEL 0..4、BT_CLR、BT_CLR_ALL。修改只影响后续按下的键，已经按住的键保留原绑定直到释放。恢复 Studio 设置仅恢复此 keymap，不清除 Wi-Fi、小智激活或蓝牙配对。

动态层使用稳定 ID 0..3，显示顺序可调整；按下时的绑定保持锁存，重排不会改变已按住键的释放行为。删除的层可恢复；至少保留一层。旧 V1 三层配置可以读取，保存时迁移成带层顺序的 V2 记录（仍使用 `keymap_v1` NVS 键）。四层及当前 61 键的最大响应保持在 4096 字节帧上限内。

运行时组合键已加入代码，hold-tap 和鼠标行为仍未完成。不支持的操作返回错误，不用成功响应冒充实现。

## 自定义 DYA 子系统

七个子系统已注册并接入实际运行状态，不再返回空列表；新增的组合键功能目前只经过本地测试，尚未编译进可下载固件：

| 子系统标识 | 已实现 | 当前边界 |
| --- | --- | --- |
| `cormoran__runtime_macro` | 8 个稳定槽位；创建、删除、重命名、重置、步骤编辑；内存修改、保存、撤销；按下、抬起、点击、延迟、紧凑键序列；键盘行为 ID 6 绑定槽位 | 共 3072 字节池，每宏最多 64 步；按键及音量媒体行为，不支持任意层/主机操作；一次播放一个宏 |
| `cormoran__runtime_combo` | 8 个组合键；2..4 个位置；名称、行为、启用、层限制、超时、前置空闲、慢释放；内存修改/保存/撤销/删除/重置；真实键、媒体键、瞬时层、宏、电脑卡槽动作 | 默认 40 ms，超时范围 1..1000 ms；候选键可能延迟，未凑齐时补回单键；配置改变需全部物理键释放后应用；尚待最终固件编译与实测 |
| `cormoran_ble` | 五卡槽真实绑定/连接信息、名字保存、选择、指定卡槽解绑、USB/BLE 输出优先级、左右手连接状态 | 不实现远程清除左右手绑定；有按键按住时拒绝切换，解绑电脑不误删键盘身份 |
| `zmk__settings` | Cube 的 idle/sleep 读写、NVS 保存、实际亮度/关机回调、中央设置通知 | 默认均为 0，不改变常亮行为；外围设置转发未实现；设置关机超时会真正关机，需按电源键重新开机 |
| `zmk__device_info` | 实际设备 MAC ID、固件版本/构建哈希、ESP-IDF 版本、板型、Flash 容量、复位原因和运行时间 | 不伪装成 Zephyr 设备或虚构外围 GPIO |
| `cormoran__watchdog` | ESP-IDF 任务看门狗监控配置任务；16 条持久化复位记录，分页查询、选删/全删、锁定保护 | 不启用危险崩溃注入；不支持外围日志转发和原生 Zephyr 冻结栈细节 |
| `cormoran__kscan_diagnostics` | 实际 61 键远程位置变化、按下/抬起次数、最短按住/间隔、短间隔计数、来源、分页及重置 | Cube 没有本地矩阵，设备数量为 0；外围 GPIO、扫描参数和诊断转发尚未实现 |

宏存储为 `cube_studio/macros_v1`，与 `keymap_v1` 分离；保存失败保留旧状态，不清空小智、网络和配对。设置位于 `activity_v1`，看门狗记录位于 `watchdog_v1`。键盘编辑器选择 Runtime Macro，参数填写宏列表中的槽位 0..7。切换输出、断开目标连接或关闭输出会取消播放，不把宏后续按键转发到其他电脑。

组合键使用 `cube_studio/combos_v1` 独立存储，校验损坏记录，不擦除其他设置。位置是 61 键布局的全局编号，支持跨左右手组合。匹配成功时抑制原单键；超时/未匹配时发回原键，提前点按通过真实 down/up 两帧保留。较长的重叠组合优先；慢释放可全局设置或逐组合覆盖。断开左右手、切换主机或关闭输出时取消组合与宏，并等待物理释放，避免旧输入重放。

这些新增功能经过编译与主机测试，仍需在新固件上验证；用户对上一版 USB/BLE 连接的成功确认不自动覆盖新增宏、休眠或日志功能。完整 DYA 接入仍在开发，不应把本表边界以外的能力视为已完成。

`codex/xingzhi-cube-dongle` 已加入 BLE Studio GATT。先将当前蓝牙卡槽的 `Cube Velvet Pro` 与电脑完成配对，再在支持 Web Bluetooth 的浏览器中选择 DYA 蓝牙连接。配置连接与键盘 HID 共用一个加密连接，只有当前卡槽已授权的电脑可写入；双击 BOOT 解锁已连接的配置会话五分钟。USB 与 BLE 解锁状态分别维护，断线或切换连接重新锁定。此路径已编译，尚待网页与实机验证；浏览器与操作系统是否提供 Web Bluetooth 需在实际环境确认。

二进制 Studio framing 与原 Codex 文本协议共用 CDC，由帧边界隔离。单帧上限 4096 字节，超过限制的帧丢弃；半帧两秒超时；断开及五分钟超时重新锁定。BLE 根据 MTU 分片，只有收到 indication 确认才推进，队列有上限，旧连接响应不会发送给新连接。新增配置保持独立存储，不整体擦除 NVS；BLE 管理仅在明确操作指定电脑卡槽时修改其绑定。

协议依据 cormoran/zmk-studio-messages `89b81d2e587fce807b668dff2a6967a40beef421`，独立实现。主机测试包含分帧/转义、协议响应、持久化损坏、保存失败、非法参数、锁定及输入释放。编译成功不等于网页或实机验证，首次安装后需确认网页载入、修改保存、重启保留及持续打字。
