# Cube 左右手自动绑定

仅 `xingzhi_cube_dual_candidate` 启用自动绑定。保留小智、USB/电脑蓝牙输出、Codex 同步和现有主题。

1. 左右手刷 `zmk-esp32-cube` 分支的新 `velvet_left_cube.uf2`、`velvet_right_cube.uf2`，Cube 刷对应的新双通道固件。
2. 初次使用时，左右手需要处于未绑定接收器状态。曾绑定旧 dongle 的键盘仍会寻找旧接收器；必要时由用户在左右手分别刷 `settings_reset.uf2` 再刷正常固件，这会清除该键盘原有配对。
3. 三台设备通电；Cube 在五秒扫描窗口收集专用左右手标识，建立加密连接，核对 GATT 身份、持久化安全密钥和矩阵所有权，再保存地址。初次绑定后松开所有按键才开始输出。
4. 后续按保存的地址重连，也接受不携带服务 UUID 的定向广播。不覆盖已有手动绑定，不删除电脑五个蓝牙卡槽或另一只手的绑定。

通用 ZMK 广播不自动绑定。同一扫描窗口发现两个同侧候选时不选择任何一个；请仅打开要绑定的一套键盘。公共配套标识用于识别固件家族，不是秘密，也不提供抗主动伪装或 MITM 身份认证。

首次配对在密钥保存与地址保存之间掉电，可能留下键盘指向 Cube、Cube 未保存地址的中间状态；这时需要重新清除该键盘配对后再绑定。运行中存储失败会保留已验证的候选身份以便重试，但不会宣称跨掉电恢复保证。

自动绑定和双通道固件仍是候选版。编译与主机测试不能代替实机的首次绑定、左右手先后启动、掉线、重启、USB/蓝牙切换及持续输入测试。
